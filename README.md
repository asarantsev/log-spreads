# log-spreads
The data and R files and the output for the article by Jihyun Park and Andrey Sarantsev.

BofA-ICE-corporates-monthly.xlsx contains monthly data for BofA ICE rated corporate bond rates, monthly from December 1996.

vix-monthly.xlsx contains monthly average VIX values from January 1990.

code.R is the main workflow code and results_summary.csv is the output.

plots.py is a simple code which made the two pictures in the manuscript.
